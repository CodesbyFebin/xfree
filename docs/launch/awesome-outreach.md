# Awesome-list outreach checklist

Prioritize lists where XFree's current release actually fits:

- browser developer tools;
- web development utilities;
- TypeScript/React tooling;
- WebGPU / WebAI;
- local AI / private AI tooling;
- privacy-friendly developer software;
- technical SEO tooling.

Do **not** target self-hosting lists unless XFree ships and documents a genuinely self-hostable distribution that satisfies that list's current requirements.

## Submission proof package

Before opening an awesome-list PR, include:

- production URL: `https://www.xfree.in`;
- recipes proof: `https://www.xfree.in/recipes`;
- source: `https://github.com/CodesbyFebin/xfree`;
- MIT license link;
- concise category-specific description;
- no fabricated usage, stars, ratings, or benchmark claims;
- a screenshot only if the target list accepts images;
- the exact feature relevant to that list rather than a generic “all-in-one platform” description.

## Example description

> XFree — open-source browser developer tools and versioned local workflow recipes. Published recipes expose their allowlisted execution steps and run without an XFree account; optional cloud features are separate and disclosed.

## Outreach order

1. Find 5–10 actively maintained lists with a precise category match.
2. Read each repository's contribution guide and duplicate policy.
3. Confirm XFree is not already listed.
4. Submit one tailored PR at a time rather than blasting identical copy.
5. Respond to maintainers with technical details and make requested formatting changes.
6. Track accepted/rejected submissions in a maintainer-owned issue or project note; do not manufacture community signals.
