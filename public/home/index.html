Why XFree?

Local by default

Tools process your data inside your browser using JavaScript and WebAssembly. The server only serves static assets — your input never leaves your device.

Verified, not advertised

Every tool in the public directory has been audited and runs on a verified local engine. We do not list tools that do not yet work.

Open source MIT

The entire XFree codebase is open source under the MIT License. Audit, fork, or self-host — the contract is permissive.

Frequently asked questions

What is XFree?

XFree is a free, open-source suite of browser-based developer, SEO, and data tools. Local Mode is the default.

Is XFree really free with no signup?

Yes. XFree is open source under the MIT License and has no signup, no accounts, and no usage limits.

How does XFree ensure privacy?

Tools process data in your browser by default. The server only receives the minimum request metadata needed to serve the static site.

Can I use XFree offline?

Yes. The XFree service worker caches the static shell so the page works without an internet connection after the first visit.

How are tools verified?

Each tool is implemented against a registered local engine. The build runs an engine audit before any tool becomes indexable.

Where is the source code?

The XFree source is available on GitHub under the MIT License.
