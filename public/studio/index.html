Local AI via Ollama (pre-routed before cloud)

If Ollama is running on your own machine, commands that don't match a built-in tool are tried against it first - nothing leaves your device. Requires Ollama started with OLLAMA_ORIGINS=https://app.xfree.in ollama serve (its default CORS policy otherwise blocks this page from reaching it) and the model already pulled (ollama pull llama3.2:1b).

Cloud Fallback Models (NVIDIA, OpenRouter, Venice, DeepSeek)

X's dedicated model is MiniMax M3 (NVIDIA, free, multimodal reasoning) - picking a free model here (including this one) requests it specifically, with automatic fallback to the task-scored free cascade if it's unavailable on this account. Kimi K3 (larger, slower reasoning) and Laguna XS 2.1 (small, fast, coding-specialized) are also available. "Auto" skips straight to the cascade. Venice and DeepSeek are paid APIs: picking one calls it directly with no fallback, so you'll see a clear error instead if it's unavailable.

MCP Connector

Connect a remote MCP server (Streamable HTTP transport, CORS-enabled for browser clients). Most desktop MCP servers use local stdio and can't be reached from a webpage at all - this only works with MCP servers built to be called directly from a browser.

Get a Free API Key

Cloud Mode needs at least one of these set as a server environment variable (NVIDIA_API_KEY or OPENROUTER_API_KEY) - this is done once by the site owner, not per-visitor.
